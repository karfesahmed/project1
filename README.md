# خريطة طريق تطوير المشروع (Project Development Roadmap)

## المرحلة 1: إعداد المشروع (Project Setup)
**الهدف:** تجهيز البيئة الأساسية للمشروع وهيكل الملفات.

### المهام
- [ ] إنشاء المشروع (Create Django Project)
- [ ] إنشاء جميع التطبيقات الأساسية (Create Django Apps)
- [ ] إعداد ملف الإعدادات `settings.py`
- [ ] إعداد مجلدات وملفات الـ `static` والـ `media`
- [ ] إعداد نظام القوالب (`templates`)
- [ ] إنشاء القالب الأساسي `base.html`
- [ ] إنشاء المكونات المشتركة `navbar` و `footer`
- [ ] إعداد الملفات الأساسية الـ `css` والـ `js`

> **النتيجة:** بعد انتهاء هذه المرحلة، يكون لديك مشروع فارغ جاهز ومنظم للعمل الفعلي.

---

## المرحلة 2: الحسابات وصلاحيات الوصول (Accounts)
**الهدف:** إعداد نظام التوثيق وتسجيل الدخول وتأمين لوحة التحكم.

### النماذج (Models)
- [ ] إنشاء نموذج مستخدم مخصص (Custom User Model)

### الخلفية (Backend)
- [ ] إعداد نظام تسجيل الدخول (Login)
- [ ] إعداد نظام تسجيل الخروج (Logout)
- [ ] حماية لوحة التحكم ومنع الوصول غير المصرح به
- [ ] تخصيص رابط سري لتسجيل الدخول (Secret Login URL)

### الواجهة الأمامية (Frontend)
- [ ] تصميم صفحة تسجيل الدخول (Login Page Layout)

---

### واجهات برمجة التطبيقات (APIs)

- [ ] تصميم صفحة الأسئلة الشائعة (FAQ)

### النماذج (Models)
- [ ] إنشاء نموذج الولايات (Wilaya Model)

### واجهات برمجة التطبيقات (APIs)

## المرحلة 5: إدارة المنتجات (Products)
**الهدف:** بناء نظام إدارة المنتجات وتفاصيلها (تعتبر أكبر وأهم مرحلة).

### التصنيفات (Category)
- [ ] إنشاء نموذج التصنيفات (Category Model)
- [ ] بناء واجهات CRUD للتصنيفات (إنشاء، قراءة، تحديث، حذف)

### المنتجات (Product)
- [ ] إنشاء نموذج المنتج (Product Model)
- [ ] API لعرض قائمة المنتجات (List API)
- [ ] API لعرض تفاصيل منتج معين (Details API)
- [ ] API لإضافة منتج جديد (Create)
- [ ] API لتعديل بيانات منتج (Update)
- [ ] API لحذف منتج (Delete)

### الصور (Images)
- [ ] إعداد نظام رفع صور المنتجات متعددة
- [ ] إعداد نظام حذف الصور
- [ ] تحديد وإدارة الصورة الرئيسية للمنتج (Main Image)

### الألوان (Colors)
- [ ] بناء واجهات الـ CRUD لإدارة ألوان المنتجات المتوفرة

### الأحجام والمقاسات (Sizes)
- [ ] بناء واجهات الـ CRUD لإدارة مقاسات المنتجات المتوفرة

### الواجهة الأمامية (Frontend)
- [ ] تصميم صفحة استعراض المنتجات
- [ ] تصميم صفحة تفاصيل المنتج الواحد
- [ ] تصميم صفحة التصنيفات

---

## المرحلة 6: إدارة الطلبات (Orders)
**الهدف:** استقبال ومعالجة طلبات العملاء وتتبع حالتها.

### الخلفية (Backend)
- [ ] API لإنشاء طلب جديد (Create Order)
- [ ] نظام التحقق من صحة البيانات المرسلة للطلب (Validation)
- [ ] نظام تعديل حالة الطلب
- [ ] تتبع سجل وتاريخ التغييرات على الطلب (Order History)

### لوحة التحكم (Dashboard)
- [ ] إدارة الطلبات قيد الانتظار (Pending)
- [ ] إدارة الطلبات المؤكدة (Confirmed)
- [ ] إدارة الطلبات الملغاة (Cancelled)
- [ ] إدارة الطلبات التي لم يتم الرد عليها (No Reply)

### التوصيل والشحن (Delivery)
- [ ] متابعة الطلبات الخارجة للتوصيل (At Delivery)
- [ ] متابعة الطلبات المستلمة والواصلة (Arrived)
- [ ] متابعة الطلبات المسترجعة (Returned)

### الواجهة الأمامية (Frontend)
- [ ] تصميم صفحة إتمام الطلب (Checkout / Order Page)
- [ ] تصميم صفحة إدارة ومتابعة الطلبات للعميل أو الإدارة

---

## المرحلة 7: الإحصائيات ولوحة التحكم (Dashboard)
**الهدف:** عرض مؤشرات الأداء والتقارير المالية والبيعية للمتجر.

### واجهات برمجة التطبيقات (APIs)
- [ ] API لحساب إجمالي الإيرادات (Revenue)
- [ ] API لحساب عدد الطلبات الإجمالي (Orders Count)
- [ ] API لتحديد المنتج الأكثر مبيعاً (Best Product)
- [ ] API لتحديد المنتج الأقل مبيعاً (Worst Product)
- [ ] إعداد فلتر مخصص لعرض بيانات الشهر الماضي (Last Month Filter)

### الواجهة الأمامية (Frontend)
- [ ] تصميم بطاقات الإحصائيات السريعة (Dashboard Cards)
- [ ] دمج الرسوم البيانية لتوضيح حركة المبيعات (Charts)

---

## المرحلة 8: نظام الإشعارات (Notifications)
**الهدف:** إرسال إشعارات فورية للمستخدمين أو الإدارة عند حدوث أي إجراء.

### الخلفية (Backend)
- [ ] إعداد الـ Service Worker
- [ ] ربط واستخدام الـ Push API لتقديم الإشعارات
- [ ] التكامل مع منصة Firebase Cloud Messaging

### الواجهة الأمامية (Frontend)
- [ ] برمجة نافذة طلب إذن إرسال الإشعارات من المستخدم
- [ ] استقبال وعرض الإشعار الفوري على الشاشة

---

## المرحلة 9: تحسينات وتجربة المستخدم (UX/UI Enhancements)
**الهدف:** رفع كفاءة استخدام الموقع وجعله أكثر سلاسة وسرعة.

- [ ] إضافة نظام تقسيم الصفحات (Pagination)
- [ ] إضافة نظام البحث السريع (Search)
- [ ] إضافة فلاتر متقدمة لتصفية النتائج (Filters)
- [ ] إضافة مؤشرات التحميل عند انتظار البيانات (Loading Spinner)
- [ ] إعداد رسائل التنبيه المنبثقة (Toast Messages) للحالات المختلفة
- [ ] تصميم صفحات الحالات الفارغة عند عدم وجود بيانات (Empty States)
- [ ] تخصيص وتصميم صفحات الأخطاء (مثل صفحة 404 و 500 - Error Pages)

---

## المرحلة 10: النشر والاستضافة (Deployment)
**الهدف:** رفع المشروع على خادم حي ليكون متاحاً للمستخدمين بشكل آمن وثابت.

- [ ] إعداد خادم الويب وخدمة التطبيق `Gunicorn`
- [ ] إعداد خادم `Nginx` كـ Reverse Proxy وإدارة الملفات الساكنة
- [ ] تهيئة وإعداد قاعدة بيانات الإنتاج `PostgreSQL`
- [ ] تثبيت وتفعيل شهادة الأمان `SSL` لتأمين الاتصال عبر HTTPS
- [ ] ربط النطاق الخاص بالمتجر (Domain Name)
- [ ] إعداد نظام النسخ الاحتياطي الدوري والآلي للبيانات (Backup)
